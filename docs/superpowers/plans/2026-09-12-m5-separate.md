# Toolbox M5（人声背景音分离）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 AI MediaKit 人声背景音分离端到端：公网 URL 输入、四种分离场景、多轨产物落盘与分别下载、Web 分离页 + 「送 ASR」工具联动、设置页补 MediaKit 凭证入口，CLI 可用。

**Architecture:** 沿用既有架构（provider 抽象/任务引擎/包络/前端模式）。新增：MediaKit REST 客户端（独立 Bearer 凭证体系）、SeparateTool（产物数量随 scene 动态）、`artifact_input` 任务输入通道（跨工具联动：分离产物 → ASR 本地识别）、设置页 MediaKit 输入框。

**Tech Stack:** 现有栈不变（resty 既有，零新增依赖）。

## Global Constraints

- 依据 [设计文档](../specs/2026-09-12-toolbox-design.md) §2.4 与 M2 时核实的官方文档（6448/2606673 指南、6448/2386113 提交、6448/2278532 查询），本计划撰写时已二次核实：
  - **提交**：`POST https://mediakit.cn-beijing.volces.com/api/v1/tools/separate-voice`，header `Authorization: Bearer <MediaKit API Key>`（与语音凭证体系独立），Content-Type JSON。body：`video_url`/`audio_url`（二选一，都传优先 video_url）、`scene`（`Audio` 默认 2 轨人声+背景 / `Music` 2 轨 / `Drama` 3 轨人声+音乐+音效 / `Narrate` 3 轨）、`output_format`（`aac` 默认 / `mp3` / `wav` / `m4a` / `flac`）。响应：`{"success":true,"task_id":"...","task_type":"separate-voice",...}`（错误时 `success:false` + error 对象）。
  - **查询**：`GET https://mediakit.cn-beijing.volces.com/api/v1/tasks/{task_id}`，同 Bearer 头。响应：`{"success","task_id","task_type","status":"running|completed|failed","result":{...仅 completed},"error":{"code","message","param","type"}仅 failed,"expires_at","created_at","finished_at","request_id"}`。
  - **result（completed）**：`voice_audio_url`（必有）、`background_audio_url`（仅 Audio/Music）、`music_audio_url`+`sfx_audio_url`（仅 Drama/Narrate）、`duration`（秒，Number）。产物 URL 为**24 小时有效的临时链接**——Tool 收到后立即下载转存本地。
  - **本地文件输入首期不支持**（mediakit:// 上传通道后续评估）：Tool 仅接受 URL 参数，设计文档 §2.4 已声明。
- **凭证**：`volc.mediakit.api_key`（config 已有键位）。鉴权失败（HTTP 401/403）→ 包装 `ErrAuth` 语义（退出码 4）；Web 设置页 `PUT /api/settings` 的 `mediakit_api_key` 后端已支持（M2 落地）。
- **REST 包络**（不变）：HTTP 200 + `{code,data,message}`；产物下载/stream 二进制例外；错误码表 0/2/3/4/5/6。
- **跨工具联动（本里程碑新增契约）**：`POST /api/tasks` 请求体新增可选字段 `"artifact_input": "<artifactId>"`——server 解析该 artifact（复用 artifactAbsPath 的 jail 逻辑）得到本地路径，注入 `files["audio"]` 传给引擎。当前仅 ASR Tool 消费 Files["audio"]；其他工具收到多余 files 无害（TaskInput.Files 原样透传）。与 file_ids 互斥（同时提供 → CodeBadRequest）。
- **产物契约**：artifacts 按场景动态：Audio/Music 场景 2 个（kind=audio，meta.track = `voice` / `background`）；Drama/Narrate 场景 3 个（meta.track = `voice` / `music` / `sfx`）。文件名 `separate/<uuid>_<track>.<ext>`。Summary：`{"scene","duration_s","tracks":["voice","background",...]}`。
- **CLI 契约**（对齐 `skills/toolbox/references/cli.md` separate 节）：`toolbox separate <url> [--scene audio|music|drama|narrate] [--format aac|mp3|wav|m4a|flac] [--out-dir path] [--json]`；`--out-dir` 指定双/三轨输出目录（默认数据目录）。退出码沿用：凭证 4、上游 3、参数 2（scene/format 非法值 → 2）。
- 面向用户文案中文；测试标准库；conventional commits；`go test ./... -count=1` 门禁。
- **轮询**：2s 起步指数退避上限 30s、总超时 15 分钟（分离是重计算任务）、ctx 优先；`status=="failed"` → 含 error.code/message 的中文错误（不可重试）。

# Toolbox M4（语音播客）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付语音播客端到端：文本/网页/对话稿三种输入生成双人播客，WS 事件流驱动逐轮进度（对话流视图），断点续传，成品音频 + 对话稿落库，CLI + Web 可用。

**Architecture:** 沿用既有架构。新增：播客 v3 WS 客户端（自实现 v3 帧协议——官方无 Go demo 包可 vendor，协议细节已从官方文档逐字节核实）、引擎 ProgressReporter 的 detail 透传扩展（对话流进度需要轮次文本到前端）、PodcastTool、CLI podcast、前端播客工坊。

**Tech Stack:** 现有栈不变（gorilla/websocket 既有依赖，零新增）。

## Global Constraints

- 依据 [设计文档](../specs/2026-09-12-toolbox-design.md) §2.3/§9 与 M1-M3 已落地契约（复用 apierr 包络、runToolSync、`_out` 重定向、sauc 包的 GzipCompress 等不得重构）。
- **播客 v3 WS 协议**（官方文档 6561/1668014 逐字节核实 + 6561/1329505 确认 event code）：
  - 端点 `wss://openspeech.bytedance.com/api/v3/sami/podcasttts`。headers：`X-Api-App-Id`(APP ID)、`X-Api-Access-Key`(Token)、`X-Api-App-Key: aGjiRDfUWi`(**v3 协议族固定值**)、`X-Api-Request-Id`(UUID，即任务 ID)。
  - **帧格式**（4 字节头 + 可选字段，大端）：byte0=`0x11`（v1 + header size 1）；byte1=消息类型(高4位)+flags(低4位)；byte2=序列化(高4位)+压缩(低4位)；byte3=0x00。
  - **上行 StartSession**：byte1=`0x94`（1001 Full-client request + 0100 with event number）、byte2=`0x10`（JSON + **无压缩**）。帧体 = event(4B=100) + session_id_len(4B) + session_id(客户端生成的 UUID) + payload_len(4B) + payload(JSON)。
  - **上行 FinishConnection**：event=2，byte1=`0x94`，payload 为空（仅 event + session_id）。
  - **下行文本帧**：byte1=`0x94`；**下行音频帧**：byte1=`0xB4`（1011 Audio-only response + 0100）。帧体 = event(4B) + session_id_len(4B) + session_id + payload_len(4B) + payload。音频帧 payload 为**原始音频字节**（无压缩）；文本帧 payload 为 JSON（无压缩，示例帧均 0x10）。
  - **错误帧**：byte1=`0xF0` + 错误码(4B) + 错误消息长度(4B) + 消息 JSON（如 `{"message":"...","code":...}`，解析容错）。
  - **event 表**：150 SessionStarted（payload 空 JSON）；360 PodcastRoundStart（`{"text_type","speaker","round_id","text"}`，round_id=-1 开头音乐、9999 结尾音频）；361 PodcastRoundResponse（**音频帧** payload=音频分片）；362 PodcastRoundEnd（`{"audio_duration":8.4,"end_time":38.2,"start_time":25.25}` 秒）；154 UsageResponse（`{"usage":{"input_text_tokens","output_audio_tokens"}}`）；363 PodcastEnd（`{"meta_info":{"audio_url":"...","input_metrics":{...}}}`，audio_url **1 小时有效**）；152 SessionFinished（合成完成）；52 ConnectionFinished（连接关闭确认）。
  - **上行 StartSession payload**：
    ```json
    {"input_text":"...","action":0,"use_head_music":false,
     "audio_config":{"format":"mp3","sample_rate":24000,"speech_rate":0},
     "speaker_info":{"random_order":false,"speakers":["id1","id2"]},
     "retry_info":{"retry_task_id":"<X-Api-Request-Id>","last_finished_round_id":N}}
    ```
    action=0 文本模式（`input_text`，≤20000 字符建议 ≤12000）；action=3 对话稿模式（`"nlp_texts":[{"speaker":"id1","text":"..."},...]`，无 input_text）；URL 模式（`"input_info":{"input_url":"..."}`，action=0 且无 input_text）；`retry_info` 仅断线重连时携带。
  - **断点续传**：连接断开且未收到 152 时，用**同一 X-Api-Request-Id** 重连，payload 加 retry_info（last_finished_round_id=已完整收到的最后轮次，round_id=-1 的开头音乐不算）。最多重连 3 次。
  - 流程：上行 StartSession → 下行 150 → [360→(361 音频)*→362]×N → 154×M → 363(可选) → 152 → 上行 2 → 下行 52 → 关闭。
- **引擎 detail 透传扩展**（本里程碑唯一跨任务契约变更，向后兼容）：`task.Event` 增加 `Detail map[string]any` 字段（json 标签 `detail,omitempty`）；engine.run 的 report 回调把 ProgressReporter 的 detail 带入 emit。前端 WS 消息自动携带。CLI 人类模式在 stderr 打印 note。
- **REST 包络**（不变）：HTTP 200 + `{code,data,message}`；流/下载端点例外；WS 不套包络。
- **产物契约**：主产物 `audio`（RoundResponse 分片按序拼接，format 同 audio_config.format）+ `dialog`（实际对话稿 JSON：`{"rounds":[{"round_id","speaker","text","duration_s"}]}`，来源 360 事件流）。若 152 收到但音频分片为空，fallback 下载 363 的 audio_url 转存（防 1h 失效）。Summary：`{"rounds":N,"duration_s":X,"speakers":[...],"usage":{...}}`。
- **CLI 契约**（对齐 `skills/toolbox/references/cli.md` podcast 节）：`toolbox podcast <text|--file|--url|--script dialog.json> [--speakers id1,id2] [--format mp3] [--head-music] [--out path] [--json]`；speakers 逗号分隔恰好 2 个。
- 退出码语义沿用：参数错误（含 script JSON 解析失败、speakers 数≠2）→ 2；凭证 → 4；上游 → 3。`exitCodeFor` 补关键词「speakers」「对话稿」→ 2。
- 进度上报：收到 362 时 `report(min(95, 已完成轮次×15), "第 N 轮对话完成（说话人 X）", detail)`；detail=`{"round_id","speaker","text","rounds_done"}`；152 → report(100)。
- 测试标准库；文案中文；conventional commits；`go test ./... -count=1` 门禁。
- **播客耗时数分钟**：客户端读 deadline 每帧 5 分钟；Tool 层总超时 30 分钟（ctx wrapper）；CLI 文档建议后台执行（skill 已有）。

const (EventStartSession=100; EventFinishConnection=2; EventSessionStarted=150; EventSessionFinished=152; EventUsageResponse=154; EventRoundStart=360; EventRoundResponse=361; EventRoundEnd=362; EventPodcastEnd=363; EventConnectionFinished=52)

package volcengine

import (
	"bytes"
	"encoding/binary"
	"testing"
)

func u32(b []byte) uint32 { return binary.BigEndian.Uint32(b) }

func TestBuildStartSession(t *testing.T) {
	frame := BuildStartSession("sess-1", []byte(`{"a":1}`))
	if frame[0] != 0x11 || frame[1] != 0x94 || frame[2] != 0x10 || frame[3] != 0x00 {
		t.Fatalf("header = % x", frame[:4])
	}
	if got := u32(frame[4:8]); got != 100 {
		t.Errorf("event = %d", got)
	}
	// session_id: len + bytes
	if got := u32(frame[8:12]); got != 6 || string(frame[12:18]) != "sess-1" {
		t.Errorf("session_id = %d %q", got, frame[12:18])
	}
	if got := u32(frame[18:22]); got != 6 || string(frame[22:]) != `{"a":1}` {
		t.Errorf("payload = %d %q", got, frame[22:])
	}
}

func TestParseAudioFrame(t *testing.T) {
	audio := []byte{0xFF, 0xFB, 0x90, 0x00} // mp3 片段样例
	var b []byte
	b = append(b, 0x11, 0xB4, 0x00, 0x00)          // 音频帧 raw 无压缩
	b = binary.BigEndian.AppendUint32(b, 361)
	b = binary.BigEndian.AppendUint32(b, 6)
	b = append(b, "sess-1"...)
	b = binary.BigEndian.AppendUint32(b, uint32(len(audio)))
	b = append(b, audio...)
	f, err := ParsePodFrame(b)
	if err != nil {
		t.Fatal(err)
	}
	if f.Event != 361 || !bytes.Equal(f.Audio, audio) || f.SessionID != "sess-1" {
		t.Fatalf("f = %+v", f)
	}
}

func TestParseTextAndErrorFrames(t *testing.T) {
	// 文本帧：event 360 + session_id + JSON payload
	var b []byte
	b = append(b, 0x11, 0x94, 0x10, 0x00)
	b = binary.BigEndian.AppendUint32(b, 360)
	b = binary.BigEndian.AppendUint32(b, 6)
	b = append(b, "sess-1"...)
	b = binary.BigEndian.AppendUint32(b, 7)
	b = append(b, `{"r_id":1}`...)
	f, err := ParsePodFrame(b)
	if err != nil || f.Event != 360 || string(f.Payload) != `{"r_id":1}` {
		t.Fatalf("f = %+v err = %v", f, err)
	}
	// 错误帧：0xF0 + code + len + msg
	var e []byte
	e = append(e, 0x11, 0xF0, 0x10, 0x00)
	e = binary.BigEndian.AppendUint32(e, 45000001)
	msg := []byte(`{"message":"invalid param"}`)
	e = binary.BigEndian.AppendUint32(e, uint32(len(msg)))
	e = append(e, msg...)
	ef, err := ParsePodFrame(e)
	if err != nil || ef.ErrCode != 45000001 || ef.ErrMsg != "invalid param" {
		t.Fatalf("ef = %+v err = %v", ef, err)
	}
	if _, err := ParsePodFrame([]byte{0x11, 0x94}); err == nil {
		t.Error("truncated should error")
	}
}

	}
}

# Toolbox M3（语音识别 ASR）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付语音识别端到端：本地文件（WS 二进制协议 nostream 模式）与公网 URL（submit/query 异步）双通道识别，CLI + Web 可用，产物含带句级时间戳的转写文本与 SRT 字幕。

**Architecture:** 沿用 M1+M2 架构（service 组装、task 引擎、provider 抽象、REST 统一包络、WS hub）。新增：火山 ASR WS 二进制协议客户端（自实现分帧）、异步 REST 客户端、`/api/uploads` 上传通道（文件经引擎 Files 传入 Tool）、识别结果页（句级时间戳 + 点击跳播）。

**Tech Stack:** 现有栈不变（Go/gin/gorm/cobra/resty/viper/gorilla/websocket + React 19/Vite/Tailwind）。

## Global Constraints

- 依据 [设计文档](../specs/2026-09-12-toolbox-design.md) §2.2/§7 与 M1+M2 已落地契约（见「既有接口契约」节）。
- **火山 ASR WS 二进制协议**（官方文档 6561/1354869 已核实；**协议实现采用官方 sauc_go demo 源码**，见下条）：
  - 接口 `wss://openspeech.bytedance.com/api/v3/sauc/bigmodel_nostream`；鉴权 headers：`X-Api-App-Key`(APP ID)/`X-Api-Access-Key`(Token)/`X-Api-Resource-Id`/`X-Api-Request-Id`(UUID)/`X-Api-Sequence: -1`。Resource-Id 默认 `volc.bigasr.sauc.duration`，可配置。
  - 帧 = header(4B) + [sequence(4B)] + payload size(4B, 大端 uint32) + payload(Gzip)；全部整数大端。官方 `NewAudioOnlyRequest(seq, segment)`：seq>0 → POS_SEQUENCE、seq<0 → NEG_WITH_SEQUENCE（最后一包）。
  - 请求 JSON（`protocol.AsrRequestPayload`）：`{"user":{"uid"},"audio":{"format","codec":"raw","rate":16000,"bits":16,"channel":1},"request":{"model_name":"bigmodel","enable_itn":true,"show_utterances":true,"enable_nonstream":false}}`；响应 `AsrResponse.PayloadMsg.Result.{Text, Utterances[{Text,StartTime,EndTime(毫秒),Definite}]}`、`AudioInfo.Duration`（毫秒）。
- **官方 SDK 集成方式（用户指定）**：官方 Go demo 包 `sauc_go.zip`（文档 6561/2628951 提供；`byted.org/...` module 无法 go get，官方发布形态即源码包）。**vendor 协议层到 `internal/provider/volcengine/sauc/`**（package sauc；文件头注明来源 https://www.volcengine.com/docs/6561/2628951 及 zip 包名），仅收录并改造 4 个文件：`header.go`、`payload.go`、`response.go`、`common.go`（协议常量/Gzip/JudgeWav/ReadWavInfo）。**必要改造（不做功能扩展）**：
  1. 鉴权改参数注入：新增 `NewAuthHeaderFrom(apiKey, appKey, accessKey, resourceID string) http.Header`；删除 `config.go` 的 `init()`/config.toml/toml 依赖与 env 函数；
  2. `sonic.Marshal` 换 `encoding/json`（去掉 sonic 依赖）；
  3. 不 vendor demo 的 `client.go`（其 Execute 强制 ffmpeg 转 WAV 且转换后删除源文件、按真实时长 ticker 发包——均不适用）；音频分片与全速发送由本项目 asr_client.go 用 sauc 原语自行实现；
  4. 音频格式 mp3/wav/ogg/pcm **原样直发**（协议支持，`audio.format` 声明即可，无需 ffmpeg）。
- **异步通道**（官方文档 6561/1354868，M2 已核实）：`POST https://openspeech.bytedance.com/api/v3/auc/bigmodel/submit`（body `{"audio_url":...}`）→ `POST .../bigmodel/query` 轮询；headers 同上 + `X-Api-Sequence: -1`（仅 submit）；Resource-Id `volc.seedasr.auc`；响应 `{"id","status":"Completed|Running|Queuing|Failed"...}`（实现时以响应实际字段为准解析 text 与 utterances，utterances 缺失则跳过 SRT）。
- **REST 统一包络**（用户硬性要求）：HTTP 一律 200，`{code,data,message}`；码 0/2/3/4/5/6；用 `internal/server/apierr.go` 的 ok()/fail()/failErr()。stream/download 二进制流例外。WS 消息不套包络。
- **既有接口契约（M1+M2 已落地，必须复用不得重构）**：
  - `provider.TaskInput{Params map[string]any; Files map[string]string}`；`task.Engine.Submit/SubmitSync(provider, tool, params, files)` 的 files 参数已贯通（本里程碑 Web 上传经它进入 Tool）。
  - `cmd/toolbox/tts.go` 的 `runToolSync(c, providerName, toolName, params, outPath, jsonOut)`：asr CLI 复用；`_out` 参数重定向首个产物路径（Tool 侧处理）。
  - `apierr.ok()/fail()/failErr()`；`skill skills/toolbox/references/cli.md` 的 asr 节是 CLI 对外契约：`toolbox asr <file|--url audio_url> [--out] [--srt] [--hotwords "词1,词2"] [--json]`；artifacts kind=`transcript`（txt）与 `subtitle`（srt）；`summary.segments` 为 `[{text,start_ms,end_ms}]`。
- 产物路径契约同 M2：Tool 返回 data 目录相对路径；`_out`/显式 out 可为绝对路径；store/CLI/stream 端的路径处理沿用（IsAbs 分支 + jail）。
- 面向用户文案中文；标识符英文；测试标准库 `testing`；`--json` stdout 单 JSON、进度走 stderr。
- 提交 conventional commits，每任务至少一次提交；`go test ./... -count=1` 全绿为门禁。
